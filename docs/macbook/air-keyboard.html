Air Keyboard

MacBook Air M2 (A2681) dead keyboard / trackpad

Written for the MacBook Air M2 2022, model A2681 (Apple Silicon). Other models differ in cabling and part numbers.

Step 1: Isolate with external devices

Plug in a USB keyboard/mouse, or pair a Bluetooth one (the trackpad works for pairing if it is alive).

  • External keyboard works, built-in is dead: The fault is in the built-in keyboard, its flex cable/connector, or the board.
  • External keyboard also fails: Suspect software (a hang or input service crash), not the hardware.

Then check the built-in trackpad. On many MacBook Airs some keyboard signals (and on some models the backlight) run through the trackpad flex cable, so a trackpad or cable fault can take out the keyboard as well. This is model dependent, so use it as a pointer, not a rule.

  • Trackpad works, keyboard dead: Points at the keyboard itself or its connection to the trackpad flex.
  • Both dead: Points at the trackpad flex cable or its connector.

Step 2: Software checks

  1. Mouse Keys: System Settings > Accessibility > Pointer Control. If on, keys move the cursor and the keyboard looks dead.
  2. Slow Keys: System Settings > Accessibility > Keyboard. Make sure it is off.
  3. Safe Mode (Apple Silicon): Shut down, press and hold the power button until "Loading startup options" appears, select the startup disk, hold Shift, click "Continue in Safe Mode".
  4. Boot picker / Recovery: Test whether keys respond in Startup Options or macOS Recovery. If they work there, the hardware is probably fine and the fault is in macOS. If they are dead there too, move on to the hardware.

There is no SMC or NVRAM reset on Apple Silicon; a full shutdown does the equivalent.

Step 3: Apple Diagnostics

  1. Shut down the MacBook Air completely.
  2. Press and hold the power button until "Loading startup options" appears.
  3. Press Cmd + D (on an external keyboard if the built-in one is dead).
  4. Note any reference codes:
    • NDK001 / NDK003 / NDK004: possible keyboard issue.
    • NDR001 / NDR003 / NDR004: trackpad problem.

NDT codes are Thunderbolt, not keyboard or trackpad. Both an NDK and an NDR code together fits a shared cable fault, but it does not prove it.

Step 4: Hardware inspection

Open the bottom case (P5 Pentalobe screws).

  1. Disconnect the battery before touching any other connector.
  2. Inspect the trackpad flex cable and its connectors (trackpad side and logic board side). Remove the retaining bracket if fitted, unplug, and look under good light/magnification.

Look for:

  • Corrosion / oxidation: Green or white deposits on the pins (liquid ingress). The connection sits just below the gap at the top of the trackpad, which is a common entry point.
  • Burn marks: Seen on the flex cable between the logic board and trackpad in some repairs.
  • Creases or fraying: Sharp folds can break traces without any visible tear.
  • Partial seating: Reseat both ends firmly, reconnect the battery and test.
  • Battery swelling: A swollen battery can strain the connector or the trackpad.

Parts (A2681)

  • Trackpad flex cable listings for the A2681 quote 821-03871 (suffixes vary, e.g. -A, -02/A). Confirm against the seller's compatibility list and the cable you remove before ordering.
  • On some models Apple treats the flex cable as part of the trackpad assembly. Check whether the cable is sold separately.
  • Apple's removal procedure for this model: MacBook Air (M2, 2022) Trackpad and Trackpad Flex Cable. The cable is glued to the top case with strong adhesive, so peel it gently.
  • Apple suggests that if a known-good trackpad and cable are available, swapping both and retesting is the way to confirm the cause.

Summary Rules of Thumb

  • Keys dead in the boot picker too, trackpad dead as well, pins clean: Replace the trackpad flex cable.
  • Corrosion on the connector or board: Clean with >90% isopropyl alcohol and an ESD brush before ordering parts. Look for other liquid damage.
  • Trackpad works, keyboard dead: Check the keyboard's own connection before ordering the trackpad cable.
  • Keys work in Recovery or the boot picker: Treat it as a macOS problem, not hardware.

Reference: Apple's Mac Laptops Troubleshooting Input/Output Issues and Apple Diagnostics reference codes.
