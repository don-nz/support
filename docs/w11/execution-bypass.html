Execution Bypass

Run a blocked PowerShell script

Run a single script, bypassing the execution policy for that run only. Replace the path with the script's location.

run one script 
powershell -ExecutionPolicy Bypass -File "C:\Path\To\Reset-WiFi.ps1"

Or bypass the policy for the current PowerShell window only, then run scripts as normal. It reverts when the window closes.

current window only 
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
