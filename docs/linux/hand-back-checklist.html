Before You Hand It Back

Drive recovery checklist

A failing drive can behave differently each time it is plugged in, and may never read again once it is disconnected. Treat the first good session as the only one.

Before you start

  • Check the drive's health with smartctl (see Live ISO Setup) and the kernel log (see Find Mount Errors). Save both outputs to a file.
  • Connect the drive directly to a SATA port where possible. A dock adds its own problems and can hide drive errors.
  • If it is BitLocker encrypted, get the recovery key before anything else. See BitLocker Drives.

Image first if the drive shows read errors

  • If you see UNC errors or rising bad-sector counts, make the ddrescue image before copying files. See Image a Failing Drive.
  • Do the copy from the image, so you can go back again later without touching the dying drive.
  • Do not run repair tools such as chkdsk on the drive.

Before you hand it back

  • Ask the owner what they need, by name: Documents, Desktop, Pictures, Downloads, email data, browser bookmarks, accounting or other program data, other user accounts. Copy Windows Folders only copies Pictures; copy the other folders the same way.
  • Have the owner check the files before you finish: open a few, check folder sizes, and look for anything missing. Do not take their word that it is all there until they have looked.
  • Keep the drive until the owner confirms. Do not take it away or return it to the original PC until they say they have everything. If they find something missing, you can plug it back in or re-copy from the image.
  • Keep the image for a few days after the job, in case something turns up missing later.
