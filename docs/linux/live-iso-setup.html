Live ISO Setup

Wi-Fi and tools on the CachyOS live ISO

Boot the stock CachyOS live ISO (from Ventoy), open a terminal and run these. Everything is installed in RAM and disappears on reboot, which is fine for a recovery session.

1. Connect to Wi-Fi or a phone hotspot. List the networks, then connect; it asks for the password. Replace SSID with the network name.

wifi 
nmcli device wifi list
nmcli --ask device wifi connect "SSID"

If no networks show, the radio may be off or blocked.

wifi radio 
nmcli radio wifi on
rfkill unblock wifi

2. Check you are online.

test 
ping -c 3 archlinux.org

3. Install the three tools in one go: ddrescue (imaging), smartmontools (drive health) and testdisk (partition and file recovery). --needed skips any already present. Refresh the package lists with -Sy but do not run a full -Syu on a live ISO, it can fill the RAM overlay.

install 
sudo pacman -Sy --needed ddrescue smartmontools testdisk

4. See how sick the drive is before choosing between a file copy and ddrescue. Find the drive name first, then run the health check (use /dev/nvme0n1 style names for NVMe drives).

drive health 
lsblk -o NAME,FSTYPE,SIZE,MODEL
sudo smartctl -H /dev/sda
sudo smartctl -a /dev/sda

Reading the result: PASSED only means the drive has not declared itself failed. Look at reallocated, pending and uncorrectable sector counts in the full output; non-zero and rising means image it with Image a Failing Drive before anything else. If it looks healthy, Copy Windows Folders is enough.
