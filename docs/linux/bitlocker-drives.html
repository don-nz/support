BitLocker Drives

Unlock an encrypted Windows drive

A Windows 11 drive is often encrypted automatically (BitLocker / Device encryption), with the key held in the original PC's TPM. Moved to a dock or another machine it will not mount, even though the drive is fine. You need the 48-digit recovery key, usually in the owner's Microsoft account at aka.ms/myrecoverykey.

1. Check whether the partition is BitLocker encrypted. Look for BitLocker in the FSTYPE column.

check encryption 
lsblk -f

2. Unlock it read-only. Enter the recovery key when prompted. Replace /dev/sda2 with the encrypted partition.

unlock 
sudo cryptsetup open --type bitlk --readonly /dev/sda2 bl_src

3. Mount the unlocked volume read-only as the source, then carry on with the copy steps.

mount source 
sudo mkdir -p /mnt/source
sudo mount -t ntfs3 -o ro /dev/mapper/bl_src /mnt/source

4. When finished, unmount and lock it again.

close 
sudo umount /mnt/source
sudo cryptsetup close bl_src

Continue with Copy Windows Folders from step 3 (the source is already mounted).
